OWM Drive Diagnostics

This only reads information from your computer — it doesn't install or change anything.

A PowerShell window should open on its own. If it does, just press Ctrl+V then Enter.

If no window opens automatically after a few seconds, do this instead:

  1. Press the Windows key, type PowerShell, and press Enter.
  2. Right-click inside the window that opens (or press Ctrl+V) to paste.
  3. Press Enter to run it.

When it finishes, scroll up, copy everything it printed, and paste it into a reply email.
