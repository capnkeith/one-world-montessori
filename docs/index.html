Checking whether OWM Drive is already running on this computer...

First, make sure you pressed the "Copy install command" button above - you need to have copied it before the paste step below will work.

A PowerShell window should open on its own. If it does, just press Ctrl+V then Enter.

If no window opens automatically after a few seconds, do this instead:

  1. Press the Windows key, type PowerShell, and press Enter.
  2. Right-click inside the window that opens (or press Ctrl+V) to paste.
  3. Press Enter to run it.

You may see a security prompt partway through - that's expected, see the on-screen instructions. Setup takes about a minute.
